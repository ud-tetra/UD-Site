A declared finite object

Exact algebra or a scoped proof on a specified carrier, metric and source convention.

02 / Computation

A reproducible execution

A frozen numerical or exact record with input hashes, tolerances and failure controls.

03 / Review

An attributable challenge

A non-constructor return bound to the exact claim or package, with its independence and scope.

04 / Correspondence

An eligible physical test

A calibrated map, units, uncertainty, baseline and a frozen independent acceptance rule.
