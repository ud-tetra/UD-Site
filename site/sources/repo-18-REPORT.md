## New exact typed consequence

Domain: a fixed labeled K4 with opposite-edge pairs \(A=(01,23),B=(02,13),C=(03,12)\), pre-state \(\Theta^-\in\mathbb F_2^3\), a sourced pair permutation \(P_g\), flip receipt \(\xi\in\mathbb F_2^3\), and six independently typed binary local edge transport-integrity values \(T_e\). Let \(Y=P_g\Theta^-\). The closure factor in this **specific pair-lift context** is \(C_{{\rm cl},e}=1-\theta_{p(e)}\); this is not a claim that all context-dependent closure requirement sets are pair-identical. Compare pre/post in the same relabeled edge frame. Then

\[
C_{{\rm cl},e}^-=1-Y_{p(e)},\quad
C_{{\rm cl},e}^+=1-(Y_{p(e)}\oplus\xi_{p(e)}),\quad
C_{{\rm cl},e}^-\oplus C_{{\rm cl},e}^+=\xi_{p(e)}.
\]

Each flipped pair changes **two closure factors**, so \(C_E^{\rm cl}=2\sum_p(1-Y_p)\xi_p\) and \(O_E^{\rm cl}=2\sum_pY_p\xi_p\). If the six \(T_e\) remain fixed across this update and \(h_e=C_{{\rm cl},e}T_e\), the counts of actual **hard-mask** closures and openings are instead

\[
C_E^{\rm hard}=\sum_p(1-Y_p)\xi_p\sum_{e\in M_p}T_e,
\qquad
O_E^{\rm hard}=\sum_pY_p\xi_p\sum_{e\in M_p}T_e.
\]

Thus \(0\le C_E^{\rm hard}\le C_E^{\rm cl}\) and similarly for openings. The two counts agree only if the flipped relevant edge transport predicates pass. If \(T_e\) itself changes, use the typed post-state \(h_e^+=C_{{\rm cl},e}^+T_e^+\); the fixed-\(T\) count theorem cannot be applied. \(U_e\) (the local edge map tested by \(T_e\)) is not the oriented global \(C_1\) transport used to recover a relative frame.

**Proof:** The XOR identity is coordinatewise over \(\mathbb F_2\); each pair has exactly two edges. A closure is \((Y_p,\xi_p)=(0,1)\), an opening is \((1,1)\). Multiplying each changing closure bit by fixed \(T_e\) gives the two weighted sums. No numeric coefficient or physical metric is introduced. `verify.py` exhausts all \(8\) pre-states, \(6\) pair permutations, \(8\) flip masks and \(64\) transport masks: **24,576** exact cases and **147,456** pair-relabeling covariance comparisons. For pre-state \((0,1,0)\) and all \(T_e=1\), flip \((1,0,0)\) closes A while flip \((0,1,0)\) reopens B; both satisfy the admitted *conditional* interface. If one A-edge transport gate is already failed, the A flip changes two closure factors but only one hard-mask bit.
