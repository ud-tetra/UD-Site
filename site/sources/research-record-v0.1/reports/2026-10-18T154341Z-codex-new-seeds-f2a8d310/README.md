## Portable phase replay

Extract the core ZIP and all four WITNESS archives listed in WITNESS_INDEX.json
into one directory. Each witness archive contains its actual floating arrays
and the corresponding original proposal needed for byte comparison. Then run:

```
OPENBLAS_NUM_THREADS=1 python replay_package.py
```

Python3.12, NumPy2.3.5, SciPy1.17.0, python-flint0.9.0 are the recorded runtime.
This verifies package hashes and recomputes all four available actual-array
phase certificates in a temporary copy. It checks the oversized HOLD/audit
receipts but does not rerun its proposer. Every float array, auxiliary reduction,
actual proposal and original proposal required by this replay is retained.

## Optional full raw-record regeneration

Raw records and the parent lossless codec are omitted to avoid duplicating
large source evidence. Obtain the UD repository with the canonical codec path
and exact hashes specified by CAMPAIGN_FREEZE.json. From the extracted package:

```
OPENBLAS_NUM_THREADS=1 python reproduce_records.py --repo /path/to/UD --destination /new/empty/path
```

This restores the baseline from the hash-checked parent codec, regenerates all
five raw records, rechecks every additive coordinate, and compares all resulting
record hashes/gate receipts with DATA_FREEZE.json. The destination must not
exist. The normal portable phase replay does not silently claim this source
reconstruction. RAW_REGENERATION_RECEIPT.json records the separate execution
performed for this campaign.
