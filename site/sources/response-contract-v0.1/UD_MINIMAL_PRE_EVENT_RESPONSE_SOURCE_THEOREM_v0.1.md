## 4. Restricted symmetry theorem

All i intact-null addresses have the same (T,L)=(1,0), so their permutations lie in that stabilizer. The selected idle mask must be constant across those addresses: h=0 or h=I. For i≥2, such a reduced deterministic selector cannot choose an intermediate count 0<j<i. The branch between empty and full may depend on the invariant profile; symmetry does not select it. Additional pre-event state, burdens, history or an admitted tie-break can break this stabilizer, but must be separately sourced. This theorem does not cover a selector using that additional information.

A stochastic kernel invariant under the same intact-null stabilizer has one probability p_j per cardinality orbit j=0,...,i. Conditioning on a supplied j gives a uniform invariant distribution on that orbit; it does not derive which j occurs.
