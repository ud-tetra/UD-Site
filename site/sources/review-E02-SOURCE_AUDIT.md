## Conditional rate/clock counterexample inside the historical packet proposal

The displayed March action is

\[
S_{\rm packet}=\sum_C\kappa\operatorname{Tr}(I-U_C)
+\sum_i\lambda(\rho_i-\rho_0)^2
+\sum_{\langle ij\rangle}\eta(\theta_i-\theta_j)^2.
\]

**Object and assumptions.** Hold graph, all `U`, `rho`, and `theta` fixed; consider one local binary branch `chi∈{0,1}`. **Condition on both `chi` values and a `chi`-only proposal being admissible** under some future explicit grammar. The displayed action contains no `chi`, so `Delta S=0` for this move and Metropolis acceptance equals 1 for any `T>0`. The source does not specify how often that move is proposed. For any `r∈[0,1]`, define a symmetric pre-event proposal kernel per **attempt**, independently across attempts,

\[
K_r=\begin{pmatrix}1-r&r\\r&1-r\end{pmatrix}.
\]

`r` is an illustrative **unsourced proposal probability**, not a UD coefficient or measured rate. Both `r=1/4` and `r=1/2` have the same displayed action, unit acceptance for a proposed branch flip, symmetry/detailed balance and uniform stationary distribution `(1/2,1/2)`. Yet the expected first-flip attempt counts are `4` and `2`; their three-attempt **strict null-window** probabilities are `(3/4)^3=27/64` and `(1/2)^3=1/8`. Their probabilities of an **unchanged endpoint after three attempts**, allowing two flips, are `9/16` and `1/2`. Thus equal stationary states and the same action/acceptance do not identify an event schedule, null frequency, or first-switch timing. `verify.py` checks all statements in exact `Fraction` arithmetic and compares powers through ten steps. An attempt index is not seconds.

**NO-GO scope.** This is a conditional logical counterexample to inferring a unique *primitive branch* update from the historical action plus acceptance formula. It does **not** prove that actual UD admits `chi`-only moves, that `chi` equals the current K4 `Theta`, or that either Markov kernel occurs physically. If an independently sourced proposal/eligibility rule prohibits these moves, that defines a narrower new branch; the action alone still did not supply that rule. Identifying `chi` with `Theta`, or inferring the pair flip receipt `xi`, would require a separate typed carrier/readout bridge.
